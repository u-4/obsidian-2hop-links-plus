# 2Hop Links Plus 0.46.1

[日本語](#日本語) | [English](#english)

## 日本語

軽い小窓から Hover Editor への切り替えを直しました（PalmWiki Home 1.7.4・1.7.5 と同じ直し方）。

- 2段目以降の小窓をクリックしても、ただ消えて Hover Editor が開かなかったのを直した
- ページプレビューの設定で「2Hop Links（軽いプレビューから編集へ）」が Cmd 必須になっていても、
  クリックで切り替わるようにした
- Hover Editor を、軽い小窓と同じ位置に開くようにした

## English

Fixes the hand-over from a light popup to Hover Editor, following PalmWiki Home
1.7.4 and 1.7.5.

- Clicking a second or later popup no longer just closes it without opening
  Hover Editor
- The hand-over works even when the page preview setting requires Cmd for
  "2Hop Links（軽いプレビューから編集へ）"
- Hover Editor opens at the light popup's position
