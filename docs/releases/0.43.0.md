# 2Hop Links Plus 0.43.0

[日本語](#日本語) | [English](#english)

## 日本語

ノートを書いている間に関連カードの並びが変わったり、計算し直したりしないようにしました。
並べ方の考え方は変えていません。

- ノートのリンク・タグ・タイトルに使う項目が変わったときだけ計算し直す。
  文章だけの入力では計算も描き直しもしない
- ほかのノートの変更は、表示中のノートと関係するときだけ反映する
- 「ランダム」の並びを名前ごとに決まった順にし、描き直しても並びが変わらないようにした。
  ランダムの結果も使い回す
- 日付のないノートを乱数で並べていた箇所をなくした
- 同じノートのままなら、「さらに表示」で広げた件数を保つ
- 編集画面と閲覧画面の両方に作っていた表示を、見えている側だけに作る。
  切り替えたときは、前の計算結果をそのまま使う

更新前に既存のプラグインフォルダをバックアップしてください。問題がある場合は、
バックアップした `main.js`、`manifest.json`、`styles.css` を戻してObsidianを再読み込みできます。

## English

This release keeps the related cards still while you write. The ranking itself is
unchanged.

- Recompute only when a note's links, tags, or title frontmatter change; typing
  text no longer triggers a recompute or re-render
- Changes in other notes refresh the view only when they relate to the shown note
- The random order is now fixed per name, so it no longer reshuffles on refresh,
  and its results are cached like other orders
- Removed random tie-breaking for notes without dates
- "Load more" expansions are kept while the same note stays open
- Results are rendered only into the visible Markdown mode instead of both the
  editor and reading view; switching modes reuses the last result

Back up the plugin folder before updating. To roll back, restore the backed-up
`main.js`, `manifest.json`, and `styles.css` and reload Obsidian.
