# 2Hop Links Plus 0.49.0

[日本語](#日本語) | [English](#english)

## 日本語

タイトルバーの 2-hop リンクへ移るボタンを作り直しました。

- アイコンが、次に押したときの行き先を示す。ノートの下の 2-hop リンクへ行くときは「↓に線」、
  ノートの先頭へ戻るときは「↑に線」
- 見た目を、縁のある丸いエレベーターのボタン風にした。2-hop リンクが見えている間は
  アイコンが色付きで光る。色は `--twohop-elevator-*` の CSS 変数で調整できる
- 2-hop リンクを別のパネル（サイドバー）に出す設定のときは、パネルの側（左右）を向いた矢印になり、
  押すと 2-hop リンクのパネルを前に出す。出ている間は「×」になり、押すと前に出ていたパネルに戻す
  （サイドバーが閉じていた場合は閉じる）。手でタブを切り替えたときもアイコンが追いつく

## English

The title-bar button that jumps to the 2-hop links has been redone.

- The icon shows where the next press goes: "arrow down to line" to the 2-hop
  links below the note, "arrow up to line" back to the note top
- It looks like a rimmed, round elevator button, lit while the 2-hop links are
  in view; theme CSS can tune it with `--twohop-elevator-*` variables
- When the 2-hop links are shown in a side pane, the button points toward that
  sidebar and brings the pane to the front; while it is showing the button
  becomes "×" and puts the previous tab back (or collapses the sidebar if it
  was collapsed). Switching tabs by hand keeps the icon current
