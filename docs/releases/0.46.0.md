# 2Hop Links Plus 0.46.0

[日本語](#日本語) | [English](#english)

## 日本語

関連カードに、Cosense のような軽い小窓を付けました（Mac などマウスで操作する端末向け）。

- カードに Cmd を押しながらマウスを合わせると、そのノートの関連カード（Links、最大10枚）を
  上に横一列で、ノートの中身を下に表示する小窓が開く
- 小窓の中のカードやリンクに Cmd を押しながら合わせると、次の小窓が重なって開き、
  たどっていける。Escape でまとめて閉じる
- 小窓の位置は空いている場所に合わせる。カードの小窓は横に出し、画面の上のほうのカードでは
  下へ、下のほうのカードでは上へ伸ばす。リンクの小窓は、入る側（下か上）に出す
- 小窓の中をクリックすると、Hover Editor（入っていなければ Obsidian のページプレビュー）に
  切り替わって編集できる。設定の「ページプレビュー」に「2Hop Links（軽いプレビューから編集へ）」
  の項目が加わる
- カードに Cmd を押しながら合わせたときに Hover Editor を直接開く動きはなくなった
- 中身の描画と小窓の仕組みは PalmWiki Home 1.7.1 の NotePreview と CardPopover に合わせた

## English

Related cards gain a light, Cosense-style popup (for devices with a mouse).

- Cmd+hover on a card opens a popup with that note's related cards (Links, up
  to 10) in a row above a read-only preview of the note
- Cmd+hover on a card or link inside a popup opens the next popup on top, so
  notes can be followed; Escape closes them all
- Popups go where there is room: a card's popup opens beside the card,
  growing downward from cards near the top and upward from cards near the
  bottom; a link's popup opens below or above the link
- Clicking inside a popup hands the note to Hover Editor (or Obsidian's page
  preview) for editing. Settings → Page preview lists "2Hop Links（軽いプレビュー
  から編集へ）"
- Cmd+hover on a card no longer opens Hover Editor directly
- The preview and popup follow NotePreview and CardPopover in PalmWiki Home 1.7.1
