# 2Hop Links Plus 0.45.1

[日本語](#日本語) | [English](#english)

## 日本語

- カードの画像を読み込む前の枠に、関連領域の地の色ではなくカードに合う淡い色を使う
  （`--cosense-card-media-bg` で上書き可能）
- 狭い表示でのカードの内側の余白を `--cosense-card-padding-narrow` で上書きできるようにした

## English

- The image area of a card shows a pale card-matching color before the image
  loads, instead of the related area's background (`--cosense-card-media-bg`)
- The card padding in narrow panes can be set with `--cosense-card-padding-narrow`
