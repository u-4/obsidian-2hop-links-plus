# 2Hop Links Plus 0.49.5

[日本語](#日本語) | [English](#english)

## 日本語

- 関連カードが画面近傍から外れたら、画像要素を外すようにしました。画像枠・タイトル・抜粋は残し、画面へ戻ると保持しているURLで画像を再表示します。
- 読込中にカードが画面外へ移った場合も、完了後に画面外の画像要素を作りません。画面内外を監視する機能がない環境では、従来どおり表示します。
- 設定、関連ノートの並び順、画像の選び方、共通CSSは変更していません。

確認した範囲はビルド、自動テスト47件、コード検査です。自動テストは画像要素の有無と表示枠・文字の保持を確認するもので、iPhone・iPadでの表示、画像のメモリ解放、起動ロゴへ戻る現象の解消は未確認です。

## English

- Remove related-card image elements when the cards leave the viewport's nearby region. Keep the image frame, title and excerpt, then restore the image from its retained URL when the card returns.
- A preview read finishing offscreen no longer adds an offscreen image element. Environments without viewport observation retain the existing display behavior.
- Settings, related-note ordering, image selection and shared CSS are unchanged.

Validation covers the build, 47 automated tests and lint. The tests check rendered image elements and preserved frames/text; they do not verify iPhone/iPad layout, browser image-memory release or resolution of returns to the app's startup logo.
