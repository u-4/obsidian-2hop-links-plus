# 2Hop Links Plus 0.46.3

[日本語](#日本語) | [English](#english)

## 日本語

軽い小窓を開いたとき、関係する部分までスクロールしてハイライトするようにしました。

- 2-hop のカードから開くと、そのまとまりのリンクを書いた行を出す
- 小窓の中のリンクから開くと、元の小窓のノートへリンクしている行を出す
- 見出しへのリンク（`[[ノート#見出し]]`）から開くと、その見出しを出す
- 該当する行が小窓の上から3分の1ほどに来るようにスクロールし、その行だけを色付けする
  （箇条書きの中の改行で区切られた行にも対応）
- 調べるのは描画済みの小窓の中のリンクだけで、ノートを余分に読まない

## English

Light popups now scroll to and highlight the relevant part.

- From a 2-hop card: the line with that group's link
- From a link inside a popup: the line linking back to the popup's note
- From a link to a heading (`[[Note#Heading]]`): that heading
- The line is scrolled to about a third of the way down and highlighted on its
  own, including soft-wrapped lines inside list items
- Only links already rendered in the popup are examined; no extra reads
