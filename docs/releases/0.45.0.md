# 2Hop Links Plus 0.45.0

[日本語](#日本語) | [English](#english)

## 日本語

カードの読み込みを軽くし、見た目を PalmWiki Home のカードに揃えました。

- 画面に近づいたカードだけ、本文を読んで抜粋と画像を出す。同時に読むのは2件まで
- 読んだ抜粋はノートの更新日時と大きさを目印に覚えておき、同じノートでは読み直さない
- 抜粋の作り方と最初の画像の見つけ方は PalmWiki Home と同じにした。画像は Obsidian が
  解析済みの埋め込み情報から探し、なければ YouTube の縮小画像や Web の画像を使う
- カードは高さ固定（220 px、狭い画面では 205 px）で、タイトル2行・画像・抜粋を並べる
- 「Show Image in the 2hop Links」の設定が効くようにした
- 色と大きさは `--cosense-card-*` の CSS 変数で上書きできる。変数がないときは
  これまでのカードの色を使う

更新前に既存のプラグインフォルダをバックアップしてください。問題がある場合は、
バックアップした `main.js`、`manifest.json`、`styles.css` を戻してObsidianを再読み込みできます。

## English

This release makes cards lighter to load and gives them the same shape as
PalmWiki Home's cards.

- Only cards near the screen read their note to show an excerpt and image, at
  most two at a time
- Excerpts are remembered by note modification time and size and are not read
  again for the same note version
- Excerpts and the first image follow PalmWiki Home: images come from
  Obsidian's embed metadata, with YouTube thumbnails or web images as fallback
- Cards have a fixed height (220 px, 205 px in narrow panes) with a two-line
  title, an image, and an excerpt
- The "Show Image in the 2hop Links" setting now takes effect
- `--cosense-card-*` CSS variables can override card colors and sizes; without
  them the previous card colors are used

Back up the plugin folder before updating. To roll back, restore the backed-up
`main.js`, `manifest.json`, and `styles.css` and reload Obsidian.
