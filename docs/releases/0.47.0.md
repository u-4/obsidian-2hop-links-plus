# 2Hop Links Plus 0.47.0

[日本語](#日本語) | [English](#english)

## 日本語

Cosense のようなホバーを、ノート本文のリンクとタイトルにも広げました（Mac などマウスで操作する端末向け）。

- 本文のリンク（閲覧画面・ライブプレビュー・ソースモード）に Cmd を押しながら合わせると、
  関連カード付きの軽い小窓が開く。小窓はリンクの下に入れば下、入らなければ上に出す
- 本文のリンクでは、Obsidian のページプレビュー（Hover Editor）は開かない。小窓の中を
  クリックすると Hover Editor に切り替わる
- 小窓では、開いたノートの中で今のノートへリンクしている行（またはリンク先の見出し）を出す
- ノートのタイトルにマウスを合わせると、このノートへリンクしているノートがタイトルの上に
  カードで横一列に並ぶ。離れて 2.5 秒ほどで消える。列のカードからも Cmd で小窓を開ける
- Hover Editor の小窓の中のリンクは、これまでどおり Hover Editor が扱う

## English

Cosense-style hovering now also covers links in the note body and the title
(for devices with a mouse).

- Cmd+hover on a link in the note body (Reading view, Live Preview, Source mode)
  opens the light popup with related cards, below the link or above it when
  there is no room
- Obsidian's page preview (Hover Editor) no longer opens for body links;
  clicking inside the popup hands over to Hover Editor
- The popup shows the line in the opened note that links to the current note,
  or the linked heading
- Pointing at the note title shows the notes linking to it as a row of cards
  above the title; it goes away about 2.5 seconds after the pointer leaves.
  Cards in the row open popups with Cmd too
- Links inside Hover Editor popups keep Hover Editor's own behaviour
