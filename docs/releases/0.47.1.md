# 2Hop Links Plus 0.47.1

[日本語](#日本語) | [English](#english)

## 日本語

- マウスやトラックパッドで操作する画面だけで、カードと本文のリンクの小窓、タイトルの上の
  カード列を動かす。iPhone や iPad をタップしたときには出さない
- 本文のリンクのうち、ノートへのリンクだけを小窓で扱う。PDF・画像・まだないノートへの
  リンクは、これまでどおり Obsidian（PDF++ など）が扱う

## English

- Popups for cards and body links, and the row above the title, run only where
  a mouse or trackpad is used; tapping on iPhone or iPad does not show them
- Only body links to notes are taken for popups; links to PDFs, images and
  missing notes keep Obsidian's own behaviour (for example PDF++)
