# 2Hop Links Plus 0.48.1

[日本語](#日本語) | [English](#english)

## 日本語

- 小窓の中のリンクや関連カードから次の小窓を開いたあと、元の小窓のリンク・カード以外の所に
  マウスを戻すと、次の小窓が 0.25 秒ほどで閉じる。元のリンクやカードに戻ったとき、次の小窓へ
  向かう途中で元の小窓を通っただけのときは閉じない

## English

- After a link or related card inside a popup opens the next popup, moving the
  pointer back onto the first popup (anywhere but that link or card) closes the
  next popup after about 0.25 s. Returning to the link or card, or crossing the
  first popup on the way to the next, keeps it open
