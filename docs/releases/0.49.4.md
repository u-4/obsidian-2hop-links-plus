# 2Hop Links Plus 0.49.4

[日本語](#日本語) | [English](#english)

## 日本語

- 小窓を出したリンクをクリックしてそのノートへ移ったあとも、小窓が出たままになっていたのを直した。
  ノートを開き直したら、マウスの下を確かめ直し、小窓や元のリンク・カードの上になければ小窓を閉じる。
  マウスが小窓の上にあるときは残すので、小窓をたどりながらノートを移ることもできる

## English

- Clicking the link a popup came from and opening that note no longer leaves
  the popup up. After a note opens, what is under the pointer is checked again;
  popups close unless the pointer is on them or on their link or card, so
  following popups while changing notes still works
