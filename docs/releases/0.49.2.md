# 2Hop Links Plus 0.49.2

[日本語](#日本語) | [English](#english)

## 日本語

- ノートのタイトルにマウスを合わせて出るカード列が、なかなか消えないことがあったのを直した。
  離れたことを、マウスの「離れた」知らせだけでなくマウスの動きでも確かめるようにし、
  タイトルが描き直されたときも消えるようにした
- 消えるまでの時間を約 2.5 秒から約 1 秒にした
- ノートをスクロールしたときは、すぐに消す

## English

- The card row shown when pointing at the note title no longer lingers. Leaving
  the title or row is also detected from pointer movement, so the row goes away
  even if the editor redraws the title
- It now hides about 1 second after the pointer leaves (was about 2.5 seconds)
- Scrolling the note hides it at once
