# 2Hop Links Plus 0.44.0

[日本語](#日本語) | [English](#english)

## 日本語

関連カードの並べ方を、推測で作った独自の点数から、Cosense が実際に使っている並べ方に
置き換えました。

- Links と Back Links を1つの Links にまとめた。関連度（Related）では、リンクしている
  ノートが先、リンクされているだけのノートが後に並ぶ
- 2-hop のまとまりは、ノートに書いたリンクの順に並ぶ。各ノートは最初に当てはまった
  まとまりに1回だけ出る。Links に出たノートは繰り返さない。100件を超えるまとまりは最後に回る
- まだないノートへのリンクも、ほかのノートが同じリンクを書いていればまとまりになる。
  誰も書いていないリンクだけが New Links に入る
- 並べ替えは Related、Modified、Created、Most linked、Title の5種類にした。
  保存済みの Random や Related score などは Related に、File name (A to Z) は Title に置き換わる
- PageRank 風の点数、表示中の候補どうしで割り引く計算、Properties の欄、
  リンク先のノートを自動で作る設定を外した
- Vault 全体のリンク表を1回だけ作り、変わったノートの分だけ直すようにした
- Tags の欄には関連度の点数がないので、Related のときは更新日時の新しい順に並ぶ

設定ファイルは読み込み時に新しい形に直して保存します。更新前に既存のプラグインフォルダを
バックアップしてください。問題がある場合は、バックアップした `main.js`、`manifest.json`、
`styles.css`、`data.json` を戻してObsidianを再読み込みできます。

## English

This release replaces the guessed related score with the related-page order
Cosense actually uses.

- Links and Back Links are merged into one Links section. With Related, notes
  the current note links to come before notes that only link back
- 2-hop groups follow the order of the links in the note. Each note appears
  once, under the first group it matches, and notes in Links are not repeated.
  Groups with more than 100 notes move to the end
- A link to a missing note forms a group when another note has the same link;
  only links nobody else has go to New Links
- Sort orders are now Related, Modified, Created, Most linked, and Title.
  Saved orders such as Random or Related score become Related, and File name
  (A to Z) becomes Title
- Removed the PageRank-style score, normalization within the shown candidates,
  the Properties section, and automatic creation of linked notes
- One vault link index is built once and updated only for changed notes
- The Tags section has no relation score, so under Related it sorts by
  modified time

Settings are migrated and saved on load. Back up the plugin folder before
updating. To roll back, restore the backed-up `main.js`, `manifest.json`,
`styles.css`, and `data.json` and reload Obsidian.
